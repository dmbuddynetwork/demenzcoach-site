Υποστήριξη επικοινωνίας για οικογενειακούς φροντιστές ατόμων με άνοια.

Άμεση βοήθεια όταν λείπουν οι λέξεις

Όταν δεν ξέρετε τι να πείτε, λάβετε μια ήρεμη φράση, ένα μικρό επόμενο βήμα και σαφή καθοδήγηση για δύσκολες στιγμές άνοιας.

Συνηθισμένες καταστάσεις και τι βοηθά

Επιθυμία για επιστροφή στο σπίτι

Μπορείτε να πείτε

Σου λείπει το σπίτι σου. Πες μου τι ήταν ιδιαίτερα όμορφο εκεί.

Τι μπορείτε να κάνετε

Προσφέρετε κάτι οικείο, όπως τσάι, ήρεμη μουσική ή ένα άλμπουμ φωτογραφιών.

Τι κρύβεται πίσω από αυτό

Αυτή η στιγμή αφορά συχνά περισσότερο την ασφάλεια και τη γνώριμη κατάσταση παρά την πραγματική τοποθεσία. Η αντιλογία μπορεί να δημιουργήσει επιπλέον πίεση.

Καλύτερα όχι: Μα είσαι στο σπίτι.

Η ίδια ερώτηση επανέρχεται συνεχώς

Μπορείτε να πείτε

Θέλεις να ξέρεις πότε φεύγουμε. Θα σου πω έγκαιρα.

Τι μπορείτε να κάνετε

Γράψτε την απάντηση καθαρά σε ένα χαρτί και δείξτε την όταν σας γίνει η επόμενη ερώτηση.

Τι κρύβεται πίσω από αυτό

Η απάντηση ίσως δεν έμεινε στη μνήμη. Μία ήρεμη, σταθερή πρόταση δίνει προσανατολισμό χωρίς να προκαλεί ενοχές.

Καλύτερα όχι: Σου το έχω ήδη πει πέντε φορές.

Αρνείται το ντους

Μπορείτε να πείτε

Θέλεις πρώτα να φρεσκαριστείς στον νιπτήρα ή να κάνεις μπάνιο αργότερα;

Τι μπορείτε να κάνετε

Ζεστάνετε από πριν το δωμάτιο και τοποθετήστε την πετσέτα και τα ρούχα σε εμφανές σημείο.

Τι κρύβεται πίσω από αυτό

Η προσωπική φροντίδα μπορεί να φαίνεται άγνωστη ή απειλητική. Μια μικρή επιλογή βοηθά στη διατήρηση του ελέγχου και της αξιοπρέπειας.

Καλύτερα όχι: Πρέπει να κάνεις μπάνιο τώρα.

Η ανησυχία ξεκινάει το βράδυ

Μπορείτε να πείτε

Απλώς αρχίζει να γίνεται ανήσυχο. Θα μείνω μαζί σου και θα κάνουμε τα πράγματα λίγο πιο ήσυχα εδώ.

Τι μπορείτε να κάνετε

Σβήστε τα δυνατά φώτα και την τηλεόραση και προσφέρετε μια οικεία, ήσυχη δραστηριότητα.

Τι κρύβεται πίσω από αυτό

Το βράδυ, η κόπωση, οι σκιές και πολλά ερεθίσματα μπορούν να αυξήσουν την ανασφάλεια. Ο προσανατολισμός και η ηρεμία συχνά βοηθούν περισσότερο από την πίεση.

Καλύτερα όχι: Πρέπει επιτέλους να κοιμηθείς τώρα.

Τα κλειδιά ή τα χρήματα έχουν εξαφανιστεί

Μπορείτε να πείτε

Ψάχνεις τα κλειδιά σου. Ας ψάξουμε μαζί στα συνηθισμένα μέρη.

Τι μπορείτε να κάνετε

Ελέγξτε ήρεμα δύο γνώριμα σημεία όπου συνήθως μπαίνουν τα πράγματα και μετά προτείνετε ένα διάλειμμα.

Τι κρύβεται πίσω από αυτό

Η κοινή αναζήτηση παίρνει το συναίσθημα σοβαρά και αποφεύγει την ενοχή.

Καλύτερα όχι: Τα έχασες πάλι.

Με κατηγορούν για κλοπή

Μπορείτε να πείτε

Ανησυχείς για τα χρήματά σου. Θα κοιτάξουμε μαζί.

Τι μπορείτε να κάνετε

Αναγνωρίστε την ανησυχία και αναζητήστε σύντομα μαζί σε έναν οικείο χώρο.

Τι κρύβεται πίσω από αυτό

Η ανησυχία φαίνεται πραγματική. Η άμυνα μπορεί να φαίνεται σαν περαιτέρω αντίσταση.

Καλύτερα όχι: Τι ανοησίες, δεν κλέβω.

Αρνείται το φαγητό

Μπορείτε να πείτε

Θα ήθελες λίγες κουταλιές σούπα ή λίγο ψωμί;

Τι μπορείτε να κάνετε

Προσφέρετε μια μικρή ποσότητα και μόνο δύο οικεία επιλογές.

Τι κρύβεται πίσω από αυτό

Οι μικρές, διαχειρίσιμες επιλογές φαίνονται λιγότερο συντριπτικές.

Καλύτερα όχι: Πρέπει να φας κάτι.

Ξεχνά να πιει

Μπορείτε να πείτε

Θα πιω ένα ποτήρι μαζί σου. Θέλεις νερό ή τσάι;

Τι μπορείτε να κάνετε

Τοποθετήστε ένα αγαπημένο, καθαρά ορατό ποτήρι σε προσιτή θέση και πιείτε μαζί.

Τι κρύβεται πίσω από αυτό

Το να κάνετε πράγματα μαζί και να παίρνετε μια απλή επιλογή δημιουργεί λιγότερη πίεση.

Καλύτερα όχι: Ήπιες πολύ λίγο σήμερα.

Το άτομο σηκώνεται τη νύχτα

Μπορείτε να πείτε

Είναι ακόμα νύχτα. Είμαι εδώ και θα σε συνοδεύσω για λίγο.

Τι μπορείτε να κάνετε

Χρησιμοποιήστε χαμηλό φωτισμό, συνοδέψτε το άτομο στην τουαλέτα και μετά πίσω στο κρεβάτι.

Τι κρύβεται πίσω από αυτό

Η ήρεμη προσέγγιση παρέχει ασφάλεια χωρίς να ξεκινήσει μια διαφωνία.

Καλύτερα όχι: Ξάπλωσε ξανά αμέσως.

Το ντύσιμο απορρίπτεται

Μπορείτε να πείτε

Θέλεις το μπλε ή το γκρι πουλόβερ;

Τι μπορείτε να κάνετε

Αφήστε δύο κατάλληλα ρούχα σε εμφανές σημείο και δώστε αρκετό χρόνο.

Τι κρύβεται πίσω από αυτό

Δύο ορατές επιλογές μειώνουν τις αποφάσεις και διατηρούν την αυτονομία.

Καλύτερα όχι: Δεν μπορείς να μείνεις με τις πιτζάμες σου.

Το άτομο θέλει να πάει στη δουλειά

Μπορείτε να πείτε

Μπορώ πάντα να βασίζομαι σε σένα. Πριν φύγεις, θα με βοηθήσεις λίγο εδώ;

Τι μπορείτε να κάνετε

Προτείνετε μια ουσιαστική εργασία που ταιριάζει με το παλιό επάγγελμα, για παράδειγμα ταξινόμηση χαρτιών, μια μικρή επισκευή ή το στρώσιμο του τραπεζιού.

Τι κρύβεται πίσω από αυτό

Η δουλειά συχνά έδινε σκοπό, δομή και αναγνώριση. Πίσω από την επιθυμία συχνά βρίσκεται η ανάγκη να νιώθει κανείς χρήσιμος.

Καλύτερα όχι: Μα είσαι στη σύνταξη εδώ και πολύ καιρό.

Το άτομο θέλει να οδηγήσει μόνο του το αυτοκίνητο

Μπορείτε να πείτε

Θέλεις να οδηγήσεις εσύ, το καταλαβαίνω. Σήμερα οδηγώ εγώ, κι εσύ μου δείχνεις τον δρόμο.

Τι μπορείτε να κάνετε

Προσφέρετε μια συγκεκριμένη ασφαλή επιλογή μεταφοράς και βάλτε τα κλειδιά μακριά από τα μάτια αν χρειάζεται.

Τι κρύβεται πίσω από αυτό

Η ανάγκη για ανεξαρτησία είναι κατανοητή· μια εναλλακτική μειώνει την απώλεια αξιοπρέπειας.

Καλύτερα όχι: Δεν μπορείς να οδηγείς πια.

Το άτομο δεν με αναγνωρίζει

Μπορείτε να πείτε

Σήμερα είμαι εδώ για σένα. Είμαι δίπλα σου.

Τι μπορείτε να κάνετε

Πείτε ήρεμα το όνομά σας, κρατήστε λίγη απόσταση και μιλήστε για κάτι οικείο αντί να εξηγείτε τη σχέση σας.

Τι κρύβεται πίσω από αυτό

Το να μη σας αναγνωρίζουν πονά, αλλά δεν είναι απόρριψη. Η ζεστασιά και η ηρεμία δίνουν ασφάλεια χωρίς να δοκιμάζεται η μνήμη.

Καλύτερα όχι: Πρέπει να ξέρεις ποιος είμαι.

Το άτομο μου φωνάζει

Μπορείτε να πείτε

Σου δίνω λίγο χώρο. Μένω εδώ κοντά.

Τι μπορείτε να κάνετε

Μειώστε τον θόρυβο, κρατήστε ασφαλή απόσταση και μιλήστε ξανά μόνο όταν η ένταση έχει υποχωρήσει.

Τι κρύβεται πίσω από αυτό

Δημιουργείτε μια ασφαλή απόσταση και ταυτόχρονα μεταδίδετε μια ήρεμη παρουσία.

Καλύτερα όχι: Ηρέμησε επιτέλους.

Άρνηση για το κέντρο ημέρας

Μπορείτε να πείτε

Θα σε πάω εκεί και θα έρθω να σε πάρω αργότερα. Μπορείς να βασιστείς σε αυτό.

Τι μπορείτε να κάνετε

Κρατήστε τον αποχαιρετισμό σύντομο και φιλικό, πείτε την ώρα παραλαβής και ζητήστε από το προσωπικό ένα οικείο καλωσόρισμα.

Τι κρύβεται πίσω από αυτό

Πίσω από την άρνηση κρύβεται συχνά φόβος για το καινούργιο ή για εγκατάλειψη. Μια σταθερή υπόσχεση επιστροφής δίνει σιγουριά.

Καλύτερα όχι: Πρέπει να πας, χρειάζομαι κι εγώ λίγη ησυχία.

Φράσεις και επόμενα βήματα

Το Dementia Coach υποστηρίζει συγγενείς που φροντίζουν ένα άτομο με άνοια. Περιγράψτε σύντομα την κατάσταση και λάβετε μια πιθανή ήρεμη φράση, ένα μικρό επόμενο βήμα και μια σαφή εξήγηση.

  • Γρήγορη βοήθεια σε αγχωτικές καταστάσεις
  • Συχνές στιγμές όπως επαναλαμβανόμενες ερωτήσεις, βραδινή ανησυχία ή προσωπική φροντίδα
  • Σύντομα μαθήματα και προσωπικό πρόγραμμα 7 ημερών
  • Αποθηκευμένες φράσεις, φωνητική εισαγωγή και ανάγνωση
  • Σύντομος έλεγχος για τον φροντιστή
