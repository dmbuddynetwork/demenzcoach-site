# Localized Store screenshot assets

These web-optimized images are derived from the final localized App Store screenshot
packages in DemenzCoach commit `0b5b4dd`.

- Canonical source: `fastlane/screenshots/refresh-20260908-v2/<store-locale>/iphone-6.9/*.png`
- Source format and size: RGB PNG, 1320 × 2868 px
- Website format and size: WebP, 640 × 1391 px, quality 80
- Motifs: quick help, situation entry, clarification, guidance, mini demo, privacy
- Directly represented App Store locales: 23

The conversion changes only dimensions and encoding. It does not edit the captured
app UI or the localized marketing headline.

Website languages without a matching App Store screenshot locale use `en-US` and
must show the localized fallback disclosure generated by
`scripts/refresh-localized-pages.mjs`.
